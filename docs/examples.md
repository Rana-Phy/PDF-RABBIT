# Example Notebooks

Worked examples live in the
[`notebooks/`](https://github.com/Rana-Phy/PDF-RABBIT/tree/main/notebooks)
directory of the repository.

To render notebooks directly inside these docs (like Glassure does), add the
`nbsphinx` extension:

1. Add `nbsphinx` to `docs/requirements.txt`.
2. Add `"nbsphinx"` to the `extensions` list in `docs/conf.py`.
3. Place your `.ipynb` files under `docs/` and list them in a `toctree`.
